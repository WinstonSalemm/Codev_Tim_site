# SEO-карта контентных страниц Codev_Tim

Дата подготовки: 28 июля 2026 г.

## Цель

Расширить органическую видимость по коммерческим запросам в Ташкенте и Узбекистане, не превращая сайт в набор шаблонных doorway-страниц. Каждая опубликованная страница должна иметь отдельный поисковый интент, реальные примеры работ, понятный CTA и локализованную версию на русском или узбекском языке.

## Кластеризация

### Коммерческий кластер

- разработка сайта Ташкент
- заказать сайт под ключ
- корпоративный сайт Ташкент
- сайт-каталог для компании
- разработка ERP-системы
- автоматизация бизнеса Узбекистан
- разработка Telegram-бота Ташкент

### Доверие и выбор подрядчика

- стоимость разработки сайта
- сроки создания корпоративного сайта
- поддержка сайта после запуска
- как проходит разработка сайта
- договор и фиксированная смета на разработку

### Информационный кластер

- как подготовить техническое задание на сайт
- чем сайт-каталог отличается от интернет-магазина
- когда бизнесу нужна ERP-система
- какие процессы стоит автоматизировать в первую очередь

## Шаблон каждой посадочной страницы

1. Один H1 с конкретной услугой и географией, если география релевантна.
2. Первый экран: кому подходит услуга, результат, CTA.
3. Блок «Что входит» с конкретными deliverables.
4. Этапы, сроки и принцип формирования стоимости.
5. 2–3 релевантных кейса из текущего реестра проектов.
6. FAQ по реальным вопросам клиента.
7. Контактный CTA с измеряемым событием GA4.
8. BreadcrumbList и Service/ProfessionalService JSON-LD только для фактически представленной услуги.
9. Внутренние ссылки на связанные услуги, проекты, контакты и инженерные материалы.

## Правила публикации

- Не создавать страницы только заменой города или нескольких ключевых слов.
- Не публиковать страницу без уникального текста, кейса или конкретного коммерческого предложения.
- Для RU и UZ писать отдельный естественный текст; не использовать машинный перевод без редакторской проверки.
- Добавлять URL в sitemap только после проверки HTTP 200, self-canonical, robots `index, follow` и корректного hreflang.
- После публикации отправлять sitemap в Google Search Console и Yandex Webmaster, затем проверять URL Inspection.

## Рекомендуемый порядок

1. Исправить DNS, canonical/hreflang и измерение конверсий.
2. Запустить три P0-страницы на русском.
3. Запустить одну локальную P0-страницу на узбекском.
4. Добавить P1-страницы и связать их с кейсами.
5. Публиковать 1–2 информационных материала в месяц, каждый — с внутренними ссылками на коммерческий кластер.
