# Коммерческая витрина Codev_Tim

Изменения от 9 сентября 2026 года. Главная отвечает на вопросы «что вы делаете», «сколько стоит» и «как заказать». Сохранены фон с сетью, светлая и тёмная темы, языки RU/UZ/EN и технические записи проектов. Приветствие, искусственный boot и заставка при бездействии больше не перекрывают содержимое.

## Посмотреть и управлять

- Локальная витрина: http://localhost:3000/ru
- Каталог всех восьми записей: http://localhost:3000/ru/projects
- Редактор акций: http://localhost:3000/ru/manage/promotions
- Запуск: `npm run dev`. Сервер доступен только с этого компьютера.
- Редактор доступен только при разработке. В production страница и API сохранения возвращают 404. Это локальный редактор файла проекта, а не административная панель основного сайта.
- Сохранение акции обновляет `content/commerce/promotions.json`. Для появления на основном сайте нужно опубликовать изменения через существующий процесс развёртывания проекта.
- Базовые цены меняются в `content/commerce/prices.json`, состав пакетов и переводы — в `src/lib/commerce/catalog.ts`.

## Акции

Включена «Сентябрьский старт»: −10% на `landing` и `bot`, с 9 сентября 2026, 00:00 до 1 октября 2026, 00:00, время Ташкента. Конец периода не включается. Получается 2 700 000 и 2 250 000 сум.

В редакторе можно добавить/удалить акцию, включить её, указать процент 1–70%, период и список пакетов. Для пересечений берётся максимальная скидка без сложения. Истёкшая или выключенная акция не применяется. Витрина показывает точное время окончания UTC+5 и пересчитывается на границе периода без перезагрузки.

Поля редактора блокируются на время сохранения. Проверяются формат, даты, названия на трёх языках и существование пакетов. Сохранение отклоняется при изменении файла другой вкладкой. API принимает запросы только от локального источника в development. Запись происходит через временный файл и переименование.

Цены для подписки на поддержку показываются за месяц. Если планируется отдельная акция на поддержку, её условия по количеству месяцев необходимо согласовать в предложении; исходная акция затрагивает только разовые пакеты.

## Заявки

На главной и странице контактов используется реальная серверная отправка через существующий Telegram Bot API или Resend. Выбранный пакет, допустимые дополнения и сумма вычисляются сервером; введённая клиентом сумма не принимается на веру. Успех отображается только после подтверждения провайдера.

Локально провайдеры не настроены. При отсутствии канала или ошибке интерфейс честно сообщает, что заявка не доставлена, сохраняет ввод и предлагает Telegram с подготовленным текстом, пакетом, дополнениями и суммой.

Для автоматической доставки на хостинге нужны уже предусмотренные переменные:

- `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CONTACT_CHAT_ID`; или
- `RESEND_API_KEY`, `CONTACT_TO_EMAIL`, при необходимости `CONTACT_FROM_EMAIL`.
- `SITE_URL` — настоящий домен для canonical и JSON-LD.

Секреты не добавлены в проект. Реальные письма и Telegram-сообщения во время проверки не отправлялись. Контакты взяты из имеющегося `content/site/config.json`: оба Telegram, оба номера, email, Instagram, GitHub.

## Проверки

`npm run test:commerce` — 13 проверок: полнота реестра, даты UTC+5, конец периода, отключение и пересечение акций, неверная конфигурация, допустимость/дедупликация дополнений, валидация контактов, пересчёт сервером, ошибки доставки и honeypot. Провайдер отправки заменён тестовой функцией: внешних сообщений нет.

Локальный API отдельно проверяется на неверный origin (403), процент (400), устаревшую редакцию (409). Редактор проверен реальным сохранением 15% и возвратом к 10%.

`npm run build` собирает production в `.next`; разработка использует `.next-dev`, чтобы проверка сборки не ломала открытый предпросмотр. Изменённые файлы проверяются ESLint и Prettier.

## Что изменилось в продаже

Техническая терминология больше не является главным маршрутом. На главной — предложение, цены, форма, калькулятор, честные условия, три примера работ, этапы и контакты. В каталоге у всех восьми записей есть коммерческое описание; технический реестр с фильтрами доступен по раскрытию. В деталях проекта предложение и цена стоят перед инженерным документом. По умолчанию открывается русский язык, сохранены переключатели на узбекский и английский.

Публикация на основном домене и приём настоящей заявки требуют отдельной проверки в окружении хостинга. Наличие локальной сборки не подтверждает production-развёртывание.
