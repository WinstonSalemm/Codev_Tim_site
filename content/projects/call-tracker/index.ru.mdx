## Overview

Call Tracker - внутренний инструмент для контроля звонков и общения с клиентами.

## Problem Statement

История контактов и договорённости должны оставаться доступными после каждого разговора.

## Business Context

Сотрудники фиксируют результаты общения, а руководитель контролирует активность команды.

## System Blueprint

Веб-интерфейс обращается к серверу Next.js; Prisma работает с PostgreSQL.

## Technology Stack

Next.js 16, React 19, TypeScript, Prisma и PostgreSQL.

## Trade-offs

Сотрудник фиксирует результат разговора. Полезность истории зависит от полноты записей.

## Roadmap

Дальнейшие изменения определяются потребностями ежедневной работы с клиентами.

## Interface Record

Карточки клиентов, история звонков, план следующих контактов и отчёты.

## Lessons Recorded

Для контроля общения важно сохранять результат разговора и следующее действие.
