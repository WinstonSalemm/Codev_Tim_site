## Overview

Завершённые Telegram-сценарии для сбора реквизитов и позиций заказа, получения PDF-договора и просмотра курсов валют.

## Problem Statement

Собрать понятный путь от входных данных до результата, сократить повторное ручное заполнение и разделить права доступа.

## Business Context

Исторический кейс заказной разработки. Название организации, её данные и рабочие подключения не публикуются.

## System Blueprint

Интерфейс, обработка запросов и хранение данных разделены по назначению.

Telegram conversation → Python and aiogram → Document API

## Technology Stack

Python, aiogram, PostgreSQL, Telegram Bot API

## Trade-offs

Разделение публичного интерфейса и внутренних операций позволяет развивать каждый сценарий отдельно.

## Roadmap

Разработка завершена. Кейс описывает выполненную работу и не означает текущее обслуживание, трудоустройство или партнёрство.
