## Overview

A completed internal application for sales, inventory, customers, contracts and finance, designed for offline work and later synchronisation.

## Problem Statement

Create a clear route from input to result, reduce repeated manual entry and separate access permissions.

## Business Context

A historical commissioned project. The organisation name, its records and production connections are not published.

## System Blueprint

The interface, request handling and data storage have separate responsibilities.

.NET MAUI desktop → ASP.NET Core API → SQLite and sync queue

## Technology Stack

C#, .NET MAUI, ASP.NET Core, SQLite

## Trade-offs

Separating the public interface from internal operations allows each workflow to evolve independently.

## Roadmap

Development is complete. This case describes delivered work and does not represent ongoing maintenance, employment or partnership.

## Interface Record

Demonstration materials use neutral data. Diagrams are labeled as diagrams; the live system and real records are not accessible.

## Lessons Recorded

Explicit data boundaries and short user journeys make verification and maintenance easier.
